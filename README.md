# Furry Actions
## Overview
A simple simultaneous turn-based strategy RPG inspired by many turn-based RPG games such as Fate/Grand Order, Honkai Star Rail, Fire Emblem, and the Final Fantasy Series.

## Features
- Simultaneous Turn-based Combat
- Party-based Team Building 
- Combat Parameters and Dynamic Status Effects
- Elemental Counter System
- Class/Role System
- Resource-driven Skill System

## Technical Highlights
- Finite State Machine-driven combat flow
- Modular Entity-Component architecture
- Resource-driven ability and effect system
- Dynamic targeting and action resolution
- Trigger-based status effect processing

## Simplified Core Gameplay Loop
Menu → Level Select → Hero Select → Battle Stage

## Project Status
This project currently focuses on the implementation of core combat architecture and gameplay systems.
While several presentation features such as finalized visuals, animations, and expanded gameplay content remain incomplete, the underlying combat framework, state management, targeting logic, and status effect systems are fully functional and were the primary focus of development.
